# Mercenary's Primer

A fan-made, mobile-first course that teaches the rules of *Gloomhaven* (2nd edition), with spaced review and a guided practice battle.

Play it: https://matheododi.github.io/mercenarys-primer/

This repo holds only the built single-file page. All art and wording are original; Gloomhaven is a trademark of Cephalofair Games, and this project is not affiliated with or endorsed by them.
